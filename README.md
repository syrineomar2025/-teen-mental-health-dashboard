## 📌 Project Overview
This project focuses on analyzing factors affecting teenagers’ mental health using an Open Data dataset from Kaggle.

The study explores relationships between:
- Stress level
- Social media usage
- Sleep habits
- Gender and age

The main objective is to identify behavioral patterns associated with poor mental health among teenagers.

---

## 📂 Dataset
Source: Kaggle Open Data

Dataset contains information about:
- Age
- Gender
- Stress level
- Daily social media usage
- Sleep hours
- Platform usage
